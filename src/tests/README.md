# 📝 Testing
- **Tests** are code that validates our program works as expected
- An **assertion** is a verification that a statement is valid. To assert means to state a fact. 
- A **regression** is a bug introduced into working software
- A test is a plain Rust function annotated with a `#[test]` attribute

Types of Tests in Rust
- **Unit tests** -> check small parts of the code, such as individual functions or modules in isolation.
- **Integration tests** -> test the interaction of multiple components within the program
