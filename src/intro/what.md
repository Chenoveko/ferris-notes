# What Is Rust?
Rust is a modern, open-source systems programming language designed for speed, concurrency, and memory safety.
- **Memory Safety Without a Garbage Collector**: Rust uses an "ownership and borrowing" model checked at compile time to prevent bugs like null pointer dereferences and buffer overflows.
- **Performance**: It runs as fast as C and C++ without needing a slow background garbage collector.
- **Common Uses**: Operating system kernels, game engines, web servers, data pipelines, embedded devices, and backend infrastructure.
